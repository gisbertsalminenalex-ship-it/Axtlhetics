# Axtlhetics

You are the lead software engineer for Axtlhetics.

This project is not a prototype. It is intended to become a real product.

Always prioritize clean architecture, scalability, maintainability and readability over speed.

Never generate quick hacks.

---

# Project

Axtlhetics is an AI-powered fitness application focused on helping users train, recover and improve over time.

The application revolves around AXIS, an intelligent assistant that will eventually use AI to provide personalized recommendations.

At the beginning of the project AXIS will use local logic and simple rules.

AI will be integrated later.

---

Axtlhetics Core (Version 0.1)

Only these modules exist:

- Calendar / History

Everything else will be added later.

# UI Principles

Every screen must have:

One clear primary action.

Plenty of whitespace.

Large touch targets.

Excellent readability.

Consistent spacing.

Reusable components.

# Code Principles

Always generate production-quality code.

Avoid duplicated code.

Use clear folder structures.

Comment only when necessary.
